# Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

## Project Description

This project focuses on streamlining IT procurement in ServiceNow by automating standard laptop order requests using Flow Designer.

## Objectives

* Automate standard laptop ordering.
* Reduce manual work in IT procurement.
* Streamline request processing and approval workflows.
* Improve efficiency and consistency in laptop order management.

## Tools and Technologies

* ServiceNow Developer Instance
* Flow Designer
* Service Catalog
* Workflow Automation

## Project Workflow

1. A user submits a standard laptop order request.
2. ServiceNow triggers the flow.
3. The flow processes the request according to the configured conditions and approval steps.
4. The request is updated based on the workflow outcome.
